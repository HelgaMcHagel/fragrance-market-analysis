# Fragrance Market Analysis

An end-to-end data analytics project exploring the fragrance marketplace through data engineering, data cleaning, statistical analysis, and interactive visualization.

Built with **Databricks, PySpark, SQL, and Python**, this project investigates fragrance brands, community ratings, dominant accords, and combinations of accords across Men's, Women's, and Unisex fragrance categories.

## Areas of Analysis

The project explores several dimensions of fragrance marketplace data:

- **Brand Analysis** — Brand identification, normalization, and marketplace data exploration.
- **Fragrance Ratings** — Analysis of community ratings and voting activity.
- **Dominant Accords** — Exploration of the most prominent fragrance accords across gender categories.
- **Accord Duos** — Investigation of two-accord combinations and their rating and engagement patterns.
- **Accord Triads** — Analysis of three-accord combinations, comparing popularity, ratings, and visibility across categories.

## Technology Stack

- Databricks
- PySpark
- SQL
- Python
- Data Visualization

## Project Focus

The goal is to transform raw marketplace and fragrance reference data into structured analytical datasets and meaningful insights, demonstrating practical applications of data engineering and analytics in the beauty and fragrance domain.
